# Synthetic measurement data

`measurements.csv` is generated by `python scripts/generate_example.py` using only Python's standard library. It contains illustrative measurements, not observations from an experiment or literature source. No private portfolio inputs are used.

For each group, the generator loops over the dose list in its source and adds each replicate offset to `baseline + slope * dose`. The group names, baselines, slopes, dose values, and replicate offsets are declared in that script. There is no randomness. Regeneration is checked byte-for-byte by pytest.

Columns: `group` (text), `dose` (nonnegative, arbitrary units), `response` (finite, arbitrary units). Replicates are individual rows; the reporter treats each row as one observation. Changing these illustrative formulas is not evidence for a biological effect.
